# 🚀 Meteor Blaster

Sebuah game arcade 2D luar angkasa dengan tema *retro-cyberpunk*, fitur peningkatan skill acak berbentuk bola bercahaya, dan sistem papan peringkat online (**Leaderboard**) yang terintegrasi langsung dengan **Supabase Database**.

Tersedia dalam 2 edisi:
1. **Web Edition (HTML5 Canvas + Node.js + Supabase)**
2. **Desktop Edition (Python + Pygame)**

---

## 🕹️ Fitur Utama

- **Pilihan 4 Tingkat Kesulitan (Difficulty Modes)**:
  - 🟢 **EASY (Santai / Pemula)**: Base HP 20.000, 5 Nyawa + Perisai Gratis, meteor lambat, skill orb sangat sering muncul.
  - 🟡 **MEDIUM (Normal / Seimbang)**: Base HP 15.000, 4 Nyawa + Perisai Gratis, kecepatan & spawn seimbang, Skor +25%.
  - 🔴 **HARD (Tantangan Pro)**: Base HP 10.000, 3 Nyawa, meteor lebih cepat & agresif, Skor +60%.
  - 💀 **EXTREME (Inferno / Hardcore)**: Base HP 6.500, 2 Nyawa, meteor super cepat & mematikan, Bonus Skor & ⚡ Energi ×2.5!
- **Dukungan Penuh Main di HP (Mobile Touch Controls)**:
  - 📱 **Drag-to-Move**: Cukup sentuh dan geser jari Anda di mana saja pada layar, pesawat otomatis mengikuti posisi sentuhan.
  - 🕹️ **Virtual D-Pad**: Tombol navigasi 4 arah di pojok kiri bawah.
  - 🔥 **Virtual Fire Button**: Tombol tembak neon di pojok kanan bawah (tahan untuk auto-fire).
- **Panduan Pemula Lengkap (Shortcut [K])**: Modal panduan komprehensif berisi penjelasan tombol keyboard, kontrol layar sentuh HP, orb skill, dan tips bertahan hidup.
- **Base Defense**: Base markas di sisi kiri dengan kubah perisai energi. Lindungi Base dari meteor dan alien yang lolos ke batas kiri.
- **Splitter Meteors**: Meteor besar yang hancur akan terbelah menjadi 2 anak meteor kecil.
- **Musuh Kroco & Boss**: Kroco alien scout drone dan Cyber Dreadnought Mothership dengan laser 3 arah.
- **Hangar & Upgrade Permanen**: Dapatkan **⚡ Energy** setiap selesai bermain untuk upgrade Wingman Drone, Base HP, Firerate, dan Bullet Damage.
- **Mode Multiplayer Co-Op (Room Code)**: Buat room, dapatkan kode 4 karakter, dan bertarung bersama teman secara real-time.
- **Leaderboard Global Supabase**: Skor otomatis tersimpan di cloud Supabase secara real-time dengan sistem failsafe offline.

## 🎮 Kontrol Permainan

### Keyboard (Komputer / Laptop)
| Tombol | Aksi |
|---|---|
| **W / A / S / D** atau **Panah** | Gerak 4 Arah (Atas, Bawah, Mundur, Maju) |
| **SPACE** *(tahan)* | Tembak Laser Otomatis (*Auto-Fire*) |
| **K** | Buka Panduan Pemula (*Tutorial*) |
| **H** | Buka Hangar & Upgrade |
| **T** | Buka Daftar Achievement / Misi |
| **M** | Buka Menu Multiplayer |
| **L** | Buka Papan Peringkat (Leaderboard) |
| **P / ESC** | Pause Permainan |

### Layar Sentuh (Smartphone / Tablet)
| Kontrol Sentuh | Aksi |
|---|---|
| **Sentuh & Geser Layar** | Pesawat langsung bergerak mengikuti jari Anda |
| **Virtual D-Pad (Kiri Bawah)** | Manuver presisi Atas, Bawah, Kiri, Kanan |
| **Tombol FIRE (Kanan Bawah)** | Tahan untuk menembak proyektil laser terus-menerus |
| **Tombol PAUSE (Kanan Bawah)** | Jeda permainan |
